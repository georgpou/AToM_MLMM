**Disposition vocabulary:** “verified within scope” means the traced code and applicable evidence agree for the stated profile. “Confirmed defect” has a proof/reproduction. “Not implemented” is missing functionality. “Physically blocked” means physical acceptance failed or required references are missing. “Not assessed” covers unavailable/unexecuted qualification. A row can contain a verified subset and a separately open obligation.

**Profiles:** A = small analytic controls, nonperiodic Reference/CPU, declared precision; actual AToM workers use Reference. M = exact MACE-OFF23-small CPU float64, neutral singlet H/C/N/O, fixed translations and zero/one admitted protein C–C cut. P = declared orthorhombic mechanical PME convention, fixed box/NVT, retained charge/LJ and fixed constraints; no dispersion correction. R = actual Reference double workers at 300 K, LangevinMiddle ≤0.5 fs, serial pair or explicit 3–8-state controller. The 64-water P/R fixtures are sparse synthetic local solvent controls, not equilibrated liquid. Q = the exact frozen neutral nonperiodic reference set, not general chemistry. No GPU, NPT, LJPME, general triclinic, actual electrostatic embedding, covalent reactions, metals or protein-affinity profile is inferred.
