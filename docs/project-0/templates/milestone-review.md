# Milestone review checklist

Use the normal worker/audit pair named `Milestone_XX_vN_worker.md` and `Milestone_XX_vN_audit.md` under that milestone's log folder. This checklist belongs inside those reports, not in a second independent acceptance file.

- [ ] State the milestone outcome and exact review scope. For M00, identify the design sections reviewed rather than claiming simulation evidence.
- [ ] Identify the specification revisions, code snapshot, and model/hardware settings relevant to the claim.
- [ ] Check the actual accepted results of every required gate and earlier milestone. Partial acceptance of a task is not full-gate acceptance.
- [ ] Check that the component results remain compatible in the same code snapshot and that required combined tests pass.
- [ ] Resolve or explicitly retain earlier findings. A newer small audit does not erase them.
- [ ] State the supported result, limits, independent review decision, and justified status update.
- [ ] Name the next small task that can proceed, rather than authorizing an entire downstream project.
