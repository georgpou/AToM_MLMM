# Small assignment template

This is an assignment brief, not a second work report. The user may supply the same information in a message instead of a separate file. The completed work still needs a worker log.

**Role:** worker / auditor / repair worker.\
**Task page and section:** repository-relative Markdown path.\
**Scope:** milestone, gate, and smaller task/test IDs.\
**Expected result:** what should be true at the end of this assignment.\
**Why:** the problem this small change addresses.\
**Do not do:** unrelated gates, refactors, experiments, or installations.\
**Budget:** user-specified resource or scope limits; otherwise one small task.\
**Required references:** the task's reading list and any specific additional section.\
**Starting snapshot:** branch/commit or exact supplied files.\
**Prior worker/audit:** actual paths or none.\
**Log folder and attempt:** use the assigned page's folder and next available number.\
**Checks:** named test IDs, expected answers, and affected earlier tests.\
**Stop when:** the requested part is done, or a named prerequisite/decision blocks it.

For an auditor, point to the worker log rather than reconstructing its scope in a new brief. For a repair worker, identify the required audit findings and preserve the existing implementation. See [assignment examples](../guides/assigning-work.md).
