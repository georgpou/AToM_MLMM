The user's requested additions are the worker/auditor handoff, model/reasoning metadata, reference documents, completion times, numbered Markdown reports, clear repair directions, and smaller assignments that control cost. This revision implements those rules, clarifies task reading routes, and simplifies explanatory prose.

The gate IDs G00-G13, milestone IDs M00-M08, seven scientific specifications, 32 requirement definitions, and original 81 planned test definitions are retained. Each gate's existing three work parts now has a stable task ID. One new named test, `P0-TEST-G01-07`, covers the original-MM inventory that G01 already required. It adds an explicit check, not new physics.

The documentation index changes to schema version 2 for task/log metadata. This is not a change to the scientific data schema. The initial statuses remain unexecuted. The documentation work log is not numerical qualification or M00 approval.
