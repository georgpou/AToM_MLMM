# AToM_MLMM project plan

Start with [AGENTS.md](AGENTS.md) and [the documentation map](docs/README.md).

The [Project 0 roadmap](docs/project-0/README.md) links each milestone and gate. Each gate gives a small reading list, task IDs, expected results, planned checks, and its exact log filenames. Current evidence is summarized in [STATUS.md](docs/project-0/STATUS.md).

For small worker/auditor assignments, use [the assignment guide](docs/project-0/guides/assigning-work.md) and [Worker_Log](Worker_Log/README.md). The user can point directly to one gate section without asking an agent to implement the entire project.

The scientific architecture remains one physical energy builder, separate transfer protocols, and shared ATM/workflow/analysis code. Mechanical embedding is the first tested target; interfaces already allow two ligand groups and environment forces without claiming actual electrostatic support.
